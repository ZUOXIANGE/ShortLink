## 技术债偿还记录

原清单 1/2/3 已偿还，处置方式与**残留约束**如下——残留部分不是缺陷，是必须由部署方知晓的边界：

| 原条目 | 处置 | 残留约束（部署方需知晓） |
| --- | --- | --- |
| 1 统计口径时区 | 引入 `IStatisticsCalendar`，`ClickEvent.Create` 的 `clickDate` 从调用方传入，`AnalyticsService.Range()` 用同一份日历算「今日」；`Analytics:TimeZone` 默认 `UTC`（与旧行为一致） | 改时区**不回溯**历史 `click_date`。切换当天会出现一次「跨日界线偏移」，长期趋势里旧数据仍按旧口径分桶。要重算必须离线重刷明细 |
| 2 缓存失效范围 | 不引入「跨实例失效广播」，把事实变成可观测的部署约束：`/health/info` 暴露 `cache.backplane` / `crossInstanceInvalidation` / `linkTtlSeconds`，启动日志在 Kubernetes 环境检测到无背板时打 `Warning` | 单实例无 Redis 仍是**合法**配置，只是从「静默降级」变成「明确不支持跨实例立即生效」；多实例必须配 Redis，否则停用/删除最长滞后一个 TTL |
| 3 地理信息 | `IGeoLocationResolver` 抽象 + `HeaderGeoLocationResolver`（默认）/ `MaxMindGeoLocationResolver`（配 `GeoIp:DatabasePath` 后启用）；mmdb 查不到或异常时回落请求头 | 仓库**不内置** mmdb 文件，需自行下载 GeoLite2 并定期更新（MaxMind 要求注册账号）；库路径配了但文件不存在会启动失败 |

3. ~~**地理信息**~~（已偿还，见上表第 3 行）
4. **迁移三份维护**：schema 变更需为 Sqlite / MySql / PostgreSql 各生成一次迁移（见 ADR 0004）。
5. **分支统计在内存里对齐**：`BuildVariantsAsync` 把「分支点击」与「分支转化」两组小结果集在内存里合并；分支数上限 20，成本可忽略，若未来放开上限需下推成一次 SQL JOIN。
6. **路由规则整表覆盖**：`PUT /links/{id}/routes` 是全量覆盖（删旧插新），分支 ID 会变化，因此历史点击只能靠分支名称归集。若需要长期稳定的分支 ID，应改为按 (link_id, name) 做 upsert。
7. **IP 名单为文本列**：`ip_allow_list` / `ip_block_list` 以逗号/换行分隔文本存储，匹配在内存里做（单链量级可接受）；规则规模上来后应拆成独立表并前置到网关层。
8. **导出上限**：短链列表流式导出以 10 万行为硬顶，超出部分不返回；需要全量时按时间分片导出。
9. **保留策略只删不归档**：`ClickRetentionService` 直接 `DELETE` 过期明细。需要长期留存归因数据时必须先补归档链路（导出到对象存储），否则开启清理即等于放弃历史明细。
10. **限流分区依赖代理头**：未开启 `ReverseProxy:TrustForwardedHeaders` 时分区键是代理 IP，全站共享一个桶——反代部署下这一项是强制的。另需注意限流只按 IP，不按账号，共享出口（企业 NAT、运营商大内网）下的用户会互相影响。
11. **MCP 只支持静态 Bearer 令牌**：未实现 OAuth 2.1 的 Protected Resource Metadata 与动态客户端注册，接入方需手工把登录令牌配进客户端。令牌过期后工具调用会直接 401，没有刷新协商。
12. **MCP 读写共用一份配额**：`Mcp:PermitPerMinute` 对全部工具生效，写工具没有单独桶。批量建链与批量查询会互相挤占，量上来后需拆分。
13. **点击队列无上限**：消息总线的本地队列不设容量上限，持续过载时表现为内存增长，而不是有界队列的截断丢写。容量规划要按最坏情况估算，或改用 `Transport=kafka` 把压力移出进程。
14. **Kafka 路径未跑真实 broker**：只保证配置正确（`Validate()` 启动期校验 + 单测覆盖），端到端消费、序列化兼容、消费组偏移在真实集群上的行为均未验证。上线前必须补一轮联调。
15. **消息存储依赖自动建表**：`Durable=true` 时靠 `AutoBuildMessageStorageOnStartup = CreateOrUpdate` 补 outbox/inbox 表。若生产要求 schema 变更走审批，需改成 `AutoCreate.None` 并接入独占的迁移流程。另：该路径目前只在 SQLite 上实测过（点击不进表、审计进表），MySql / PostgreSql 未验证。
16. **来源地默认依赖可信请求头**：未配 `GeoIp:DatabasePath` 时，国家/省份直接取自 `CF-IPCountry` / `X-Country` / `X-Province`。只有在 CDN 或反向代理**剥离客户端同名头**之后才可信；裸暴露到公网时，来源地维度可被任意伪造——条件路由按国家分流也会被绕过。公网部署应先接 CDN 或启用离线库。
17. **离线库更新需重启**：`MaxMindGeoLocationResolver` 在构造时打开 mmdb 并持有句柄，替换库文件要重启实例；也没有库版本探测与「库过期」告警。GeoLite2 按月发布，长期运行需把替换动作纳入发布流程。
